# Быстрый запуск PinkChat

Supabase URL и Publishable key уже подключены.

## Остался один обязательный шаг

1. В Supabase откройте **SQL Editor**.
2. Нажмите **New query**.
3. Откройте файл `supabase/schema.sql` из проекта и скопируйте весь текст.
4. Вставьте его в SQL Editor и нажмите **Run**.
5. После успешного выполнения опубликуйте папку PinkChat через GitHub Pages или другой HTTPS-хостинг.

После этого можно регистрировать два аккаунта и переписываться между телефонами.

## Уведомления

Push-уведомления пока не включены. Сначала запускаем переписку и фото, затем отдельно добавим уведомления.

## Безопасность

Никому не передавайте Secret key, service_role или пароль базы данных. Publishable key в `config.js` разрешено использовать в браузере при включённых RLS-политиках из `schema.sql`.
