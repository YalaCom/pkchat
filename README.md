# PinkChat 💗

Розовый PWA-мессенджер с чатами, фото, историями, редактированием и удалением сообщений, профилями, темами и админ-панелью.

## Публикация
Проект подготовлен для GitHub Pages через `.github/workflows/deploy-pages.yml`.

## Безопасность админа
Пароль администратора не хранится в публичном репозитории. Сначала зарегистрируй аккаунт через Supabase Auth, затем выдай ему роль через `supabase/admin_setup.sql`.
